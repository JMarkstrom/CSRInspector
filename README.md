# CSRInspector

## ℹ️ About
CSRInspector is a Windows GUI app that helps validate YubiKey PIV attestation. The app takes in three files: CSR, Attestation certificate and the Yubico Intermediate CA certificate (F9) to perform CA chain and public key validations.
